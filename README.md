
# Online Doctor Appointment Management System

## Project Description

The Online Doctor Appointment Management System
is a web-based application that allows patients
to book doctor appointments online.

Patients can enter their details, select doctors,
choose appointment dates and times, and manage
their appointments.

## Technologies Used

- Frontend: React (Vite)
- Backend: Node.js
- Framework: Express.js
- Database: MySQL
- Database Server: XAMPP
- Code Editor: VS Code

## Main Features

1. Patient appointment booking
2. Doctor selection
3. Appointment date and time selection
4. Doctor availability checking
5. View appointments
6. Cancel appointments

## Installation

### Frontend

cd frontend
npm install
npm run dev

### Backend

cd backend
npm install
node server.js

## Database Setup

1. Start Apache and MySQL in XAMPP.
2. Open phpMyAdmin.
3. Create database doctor_db.
4. Import database/doctor_db.sql.
